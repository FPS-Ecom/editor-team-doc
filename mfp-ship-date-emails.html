MFP Ship-Date Update Emails

Rules & template for telling customers their My Fireplace Products (MFP) wood stove or insert has a later ship date. Bookmark this page.

Overview

We email customers from support@firepitsurplus.com when their wood stove or insert from My Fireplace Products (MFP) has a later ship date, so they can wait, switch to an in-stock unit, or cancel. Each email covers one order from the team's list and names only the main item.

Shopify supplies the customer's name, email and product name. MFP emails supply the ship date: the latest status update that lists the main item, or else the order confirmation. If that date is already past, or any detail is missing, the order is flagged to the team instead of emailed.

Rules

1Only listed orders.

Email only the Shopify order numbers on the team's list. Never email from the MFP confirmations alone: some are repeats, and some orders aren't delayed.

2Match the MFP confirmation by PO number.

All confirmations arrive in the "Your My Fireplace Products order confirmation" Gmail thread. The MFP "PO number" equals our Shopify order number (PO 8660 = order #8660). Note the MFP order number on that confirmation (for example, #20000021479); status updates use only that number.

3Customer name and email come from Shopify.

Use the customer name on the Shopify order (which matches the MFP shipping name) and the Shopify customer email.

4Product name comes from Shopify.

Use the Shopify line-item title, not MFP's name ("Drolet Columbia II Wood Stove", not "Wood Stove - COLUMBIA II").

5Mention the main item only.

The wood stove or wood insert is always the main item. Leave out add-ons such as faceplates, blowers, firescreens and pipe kits.

6Ship date = the latest MFP status update for the main item.

Search "Your MFP Order Status has been Updated" emails for the MFP order number. Use the "YOUR ORDER IS SCHEDULED TO SHIP BY" date from the most recently sent one that lists the main item's SKU. Updates can cover add-ons only (a blower or firescreen), so skip any that don't list the stove or insert. If no status update lists the main item, use the "Estimated ship date" on the order confirmation. Write the date as YYYY-MM-DD.

7Stove vs insert wording.

If the main item is a wood insert, say "wood insert" in both spots in the body. Otherwise say "wood stove".

8Past-dated = stop.

If the ship date from rule 6 is today or earlier, do NOT send. Alert the team; they check with MFP and send that email manually.

9Send from support@firepitsurplus.com.

Send from support@firepitsurplus.com, with the Gmail signature added under "Best regards,".

10One email per order.

Before sending, check the customer hasn't already gotten this update (for example, #8660 got a test send on 2026-11-19).

11Alert, don't guess.

If an order is missing from Shopify, has no matching MFP confirmation, or has no clear wood stove or insert, skip it and flag it to the team.

When to stop and flag the team

Do not send. Flag the order to the team instead, if any of these is true:
  • The order number isn't on the team's list.
  • The order can't be found in Shopify.
  • There is no MFP confirmation with a matching PO number.
  • There is no clear wood stove or wood insert on the order.
  • The ship date (rule 6) is today or earlier.
  • The customer has already received this update for this order.

Before you hit send

  1. Order number is on the team's list. Rule 1
  2. MFP confirmation matched by PO number; MFP order number noted. Rule 2
  3. Customer name, email and product name copied from Shopify. Rules 3–4
  4. Only the stove or insert is named; no add-ons. Rule 5
  5. Ship date taken from the latest status update that lists the main item's SKU (or the confirmation if none), written as YYYY-MM-DD. Rule 6
  6. "wood stove" or "wood insert" used in both spots. Rule 7
  7. Ship date is in the future. Rule 8
  8. Sending from support@firepitsurplus.com with the Gmail signature. Rule 9
  9. Customer hasn't already received this update. Rule 10

Template

Fill every [bracketed] field. Say "wood stove" or "wood insert" in both spots. Nothing else in the body changes.
Hi [customer name],

I wanted to update you regarding your order.
The manufacturer just informed us that the [Shopify product name] you ordered has an estimated ship date of [MFP ship date].

If you would like to select an alternative in-stock [wood stove / wood insert] or cancel your order, please call us at 888-671-4611 and press 1 for Sales for immediate assistance.

Otherwise, we are keeping you first in line for this best-selling [wood stove / wood insert], and once it arrives in the US it will ship directly to you from the manufacturer.

Best regards,
[Gmail signature]
